# 官网与登录页 UI 改版验收

本次仅修改品牌官网 `/` 和登录页 `/login`，提供本地预览，不发布线上。
Sites 项目是指向 `https://aitradecloud.top/main` 的入口；当前源码中
`/main` 匹配商家商品前台路由 `/:tenantSlug`，未纳入本次改版。

## 实现

- 海军蓝与冷青色视觉体系，完整浅色模式；尊重已保存的主题选择。
- 官网主视觉为标明示例数据的“商品资料—智能匹配—报价交付”流程。
- 现有三个套餐的价格和权益与改版前源码逐项一致。
- 登录页采用桌面双栏、移动单栏；复用认证 API、语言切换和工作区选择。
- 错误信息持续显示在表单内，输入框关联真实的 `login-error` 区块。
- 工作区切换期间保留选择界面并禁用按钮；失败后可以重试。
- GSAP 动态加载，组件卸载和减少动效偏好变化时清理动画。
  默认内容可见，动画模块加载失败不会阻塞阅读或操作。
- 页面样式采用 CSS Modules，共享变量限定在公开页面容器内。

## 已验证

使用 Playwright MCP 0.0.83 与独立 Edge 浏览器完成验收；所有 API 请求均被
本地模拟响应拦截，没有登录或修改真实业务账号。

- 1440、768、390 像素：官网与登录页、深浅主题，共 12 个布局场景，无横向溢出。
- 移动菜单打开、Escape 关闭、焦点返回、锚点导航关闭菜单、套餐入口进入登录页。
  锚点预留固定导航高度，移动端套餐区顶部约 88.2px，导航高 73px，标题不被遮挡。
- 主题和语言切换及刷新后的持久化，移动端英文布局。
- 必填校验、密码显示与隐藏、Enter 提交、提交期间禁用表单。
- 401 密码错误、429 频率限制、503 服务不可用的表单内反馈。
- 会话恢复期间禁用输入，过期会话完成后恢复可操作状态。
- 空工作区、停用工作区、长名称、切换失败重试、加载状态和请求参数。
- 默认跳转 `/console`，以及登录前指定目的地的保留。
- 减少动效模式、GSAP 模块加载失败时仍可读取页面。
- 无未捕获的浏览器运行时错误；正常页面和交互阶段无控制台错误。
  故障模拟阶段出现的 HTTP 错误与模块加载错误属于预期注入。
- 现有 `test:auth` 和 `test:account` 通过；TypeScript 与生产构建通过。

截图保存在仓库本地的 `.runtime/ui-review/`（不纳入 Git）。包括各宽度、主题、
英文登录、错误状态、工作区选择和减少动效模式。已人工查看桌面完整页面和
移动页面截图。

## 复查方式

在仓库根目录安装独立浏览器验收工具（不会添加到产品依赖）：

```powershell
npm install --prefix .runtime/browser-tools @playwright/mcp@0.0.83 @modelcontextprotocol/sdk@1.31.0 --no-audit --no-fund
```

在 `apps/web` 启动本地预览，另开终端执行测试：

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5178 --strictPort
```

```powershell
npm run test:public
npm run test:auth
npm run test:account
npm run build
```

`test:public` 使用独立 Playwright 浏览器运行相同的验收场景，依赖本机 Edge，
支持通过 `UI_TEST_URL` 指定其他本地预览地址；生成截图与 JSON 结果。

## 限制

认证验收证明前端在模拟响应下的交互与跳转行为；未验证线上认证服务。
生产构建仍提示部分包体超过 500 kB，本次没有扩大范围重构工作台或图表依赖。
线上内容、Sites 指向与访问权限均未修改。

## Cloud Shader 本地试用（2026-10-02）

- 使用 [Aceternity Cloud Shader](https://ui.aceternity.com/components/cloud-shader)
  官方 registry 源码，采用官方手动安装方式；本项目使用 CSS Modules，
  没有引入 Tailwind/shadcn 全局样式或新增 npm 运行时依赖。
- 仅官网首屏增加深蓝青色云层，浅色主题使用淡青灰云层；登录页保持原设计。
- 首屏按钮可以暂停/继续云层，减少动态效果时只绘制静态云层。
  离屏、隐藏标签页时停止绘制；渲染帧率上限 30fps，画布宽度上限 960px。
- 修正产品示意装饰网格拦截移动端暂停按钮点击的问题；
  `test:public` 增加了各宽度、主题下对暂停/继续按钮的实际点击检查。
- Playwright MCP 实际检查了 390/768/1440px 深浅主题、暂停/继续、暂停时
  切换主题、离屏停止及返回恢复、减少动态效果的初始与运行中切换、
  WebGL context 丢失/恢复、卸载清理，以及 WebGL 不可用时的静态降级与登录入口。
  这些检查无未捕获的页面运行时错误；故障模拟没有操作真实业务账号。
- 更新后另行运行 `test:public` 全部通过（正常阶段无控制台错误），
  TypeScript 检查与最终 Vite 生产构建通过；仍有原有大包体告警。
- 云层截图另存为 `.runtime/ui-review/cloud-*.png`；桌面首屏为
  `cloud-home-desktop.png`，移动首屏为 `cloud-mobile-final.png`。

WebGL 会增加 GPU 工作量；上述尺寸检查使用本机 Edge，不代表已经测试低端
手机的实际帧率或耗电。浏览器验收使用本地预览，未发布到线上。
