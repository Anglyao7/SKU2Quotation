# 统一商品排序入口

- 「页面与展示 → 商品排序」统一管理手动优先、自动爆款和分类优先。
- 默认全部商品顺序：手动优先 → 自动爆款 → 优先分类 → 其余商品。后台编辑列表与前台共用数据库排序，并在排序后分页。
- 自动爆款选取最近 90 天具有正热度的前 20 个商品，热度沿用浏览量 + 有效询价数量 × 20。自动项显示已勾选，区分自动与手动来源；取消会持久保存，切换开关和刷新不会覆盖人工取消。关闭自动排序不取消手动优先。
- 分类优先支持添加、移除、上移、下移，覆盖子分类与额外关联分类；不修改分类导航、搜索结果或分类内浏览顺序。
- 主账号和各子账号独立保存偏好；子账号隐藏商品不参与自动候选和列表，设置不修改共享源商品。
