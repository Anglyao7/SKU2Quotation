# 后台操作整理（2026-09-07）

开发分支：`codex/current-latest`。沿用 React / Radix，桌面后台优先；不改客户前台布局，不迁移数据库，不改变价格计算、账户隔离、审批及导入规则。本次未合并 primary，未部署。

## 导航与入口

| 分组 | 内容 |
| --- | --- |
| 工作 | 概览、任务记录 |
| 商品 | SKU 商品库、分类、标签、AI 搜索管理、图片搜索管理 |
| 销售 | 客户询价、报价模板、客服管理 |
| 店铺设置 | 商家资料、页面与展示、多语言、公告、客服入口 |
| 经营 | 进销存、供应链、子账号管理 |
| 数据统计 | 网站监测 |
| 智能体管理 / 平台管理 | 保留管理员原有功能，平台区域增加分隔 |

- 客户询价默认进入前台客户提交的询价表格，可搜索客户/单号/国家，按状态、日期筛选，每页 20/50/100 条，直接制作报价单或查看详情。
- 手动创建询价仍在“手动新建询价”；已有正式报价保留在“历史报价”。原 `/console/inquiries` 和报价工作台地址不删除，两种业务数据不擅自合并。
- 概览中的旧询盘指标仍属于旧询盘模型；旧报价指标进入“历史报价”，不冒充前台询价数量。
- “个人中心”原本管理客服悬浮球与欢迎语，更名为“客服入口”。账户安全保留在头像入口；商家名称、Logo、分享副标题移到“店铺设置 → 商家资料”。
- 菜单继续按权限隐藏；子账号仍使用自身商品/订单页面，父账号不能修改子账号询价。配置中心与平台翻译保持管理员权限。

## 商品库

- 保留商品行与展开 SKU 的原有数据结构。批量摘要明确显示商品数及 SKU 数，不再把商品数量称为 SKU 数量。
- 行内保留商品详情，分享、翻译等次要操作收进“更多”；导出名称为“导出商品与 SKU”。
- 分类筛选、新建商品的分类支持搜索；批量“移动分类”支持搜索及多选，移动后替换原有分类，仅保留本次选中的目标分类（2026-09-08 修正）。
- 收紧表格字号、列宽、按钮与筛选间距；价格范围允许换行。1440 和 1280 桌面检查中，页面及商品表格没有横向溢出。
- 图片变清晰入口在商品和 SKU 详情中同样检查管理员身份，后台接口权限不变。

## 子账号与保存反馈

- 子账号详情分为“基础信息 / 商品与价格 / 客户询价”。价格管理嵌入独立标签页，不再依赖大弹窗；统一加价、分类、商品和 SKU 的计算优先级不变。
- 同一子账号切换标签保留价格草稿。统一/分类价格、语言设置、报价工作台有未保存离页提醒。
- 报价工作台区分未保存、保存中、已保存、保存失败及只读；服务端响应成功后才标记保存。
- 自动保存设置与商品修改串行，避免返回的旧快照相互覆盖；请求期间新输入不会被已完成请求清空。相同失败内容停止自动重复提交，可以修改或主动点击保存重试。
- PI / 装箱单的有效编辑纳入自动保存；不完整的额外信息保留在本地并阻止保存/导出，不静默丢弃半条信息。

## 任务记录

新地址 `/console/tasks`，聚合现有服务端记录：最近 30 个导入批次、最近 20 个清晰化任务、最近一次文字/图片索引、管理员当前商家每种语言最近一次翻译。

- 可按类型/名称搜索、按状态筛选，展示进度并回到具体功能；清晰化任务直接打开已有任务审核，不会重新生成。
- 导入任务可通过 `?import=1&job=…` 回到详情；翻译可通过商家和语言参数回到对应工作区。
- 状态统一处理不同接口的大小写及 `published` / `SUCCEEDED` 等差异。
- 每 30 秒刷新，页面隐藏时暂停；单一来源失败不清掉其他任务，支持重试。
- 这不是无限保留的全量审计历史；没有为 UI 再复制一份任务或新增任务数据库。

## 两个确认修复的 bug

1. **翻译页面重复面板**：自动增量控件与译文编辑器是同级组件，但原先使用相同 `key`。改为不同前缀，同时保留商家与语言标识，避免刷新/轮询时错误复用节点。
2. **主账号商品显示“子账号销售价”**：原判断依据供应商是否为空。改为销售单价文案，不再用供应商字段推断账号身份。
